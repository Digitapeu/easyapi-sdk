# Efactura

## Overview

e-Factura invoice upload, clearance state, downloads and validation.

### Available Operations

* [upload](#upload) - Upload a UBL/JSON invoice to e-Factura
* [status](#status) - Get an invoice's e-Factura clearance state
* [download](#download) - Get a signed download URL for an invoice's e-Factura result
* [downloadZip](#downloadzip) - Download an invoice's e-Factura result zip through a signed link
* [listMessages](#listmessages) - List e-Factura messages for a connected company
* [validate](#validate) - Validate a UBL invoice offline, and with ?online=true also at ANAF (no ANAF connection required)
