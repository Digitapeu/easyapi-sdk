# Procurement

## Overview

Public procurement contracts, tenders, direct purchases and CPV analysis.

### Available Operations

* [listCompanyContracts](#listcompanycontracts) - List a company's public procurement contracts by CUI
* [listCompanyTenders](#listcompanytenders) - List a company's public procurement tenders by CUI
* [listCompanyDirectPurchases](#listcompanydirectpurchases) - List a company's public procurement direct purchases by CUI
* [listCpvContracts](#listcpvcontracts) - List public procurement contracts for a CPV code
* [getCpvAnalysis](#getcpvanalysis) - Get market analysis for a CPV code
* [getContract](#getcontract) - Get a single public procurement contract's detail by number
