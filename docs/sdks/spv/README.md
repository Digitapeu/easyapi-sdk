# Spv

## Overview

SPV inbox messages, documents and the e-TVA return.

### Available Operations

* [listMessages](#listmessages) - List SPV inbox messages
* [downloadDocument](#downloaddocument) - Download one SPV document as a binary stream
* [getEtvaDecont](#getetvadecont) - Fetch the e-TVA pre-completed VAT return for a period
