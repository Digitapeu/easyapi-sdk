# Legislation.Bills

## Overview

### Available Operations

* [list](#list) - List parliamentary bills
* [listChanges](#listchanges) - Poll the bills change-feed since a given timestamp
* [get](#get) - Get a single parliamentary bill
* [listStages](#liststages) - Get a bill's legislative stage history
* [listDocuments](#listdocuments) - Get a bill's associated documents
